## Хэсэг A: Category-Partition — `POST /transfer`

**Тест хийх орчны таамаглал (setup-ийн анхдагч утгууд):** from данс `ACC-A` (MNT, үлдэгдэл 1 000 000), to данс `ACC-B` (MNT), өдрийн лимит 500 000 MNT, ханш 1 USD = 3 500 MNT. Үлдэгдэл болон лимитийг **хөрвүүлсний дараах MNT дүнгээр** шалгана.

**Олон алдааны давуу эрэмбэ (өөрөө тогтоосон):** `from` (NO_FROM → FROZEN) → `to` (NO_TO → SAME_ACCOUNT) → `amount` (BAD_AMOUNT → INSUFFICIENT → LIMIT).
**Үндэслэл:** эхлээд хэн шилжүүлж байгааг (эрх), дараа нь хэнд шилжүүлж байгааг, хамгийн сүүлд мөнгөн дүнг шалгах нь хүсэлтийн талбарын дараалал болон банкны бодит логиктой нийцдэг. Мөн царцаагдсан данстай хүнд хүлээн авагчийн данс эсвэл үлдэгдлийн мэдээллийг задруулахгүй.

### A1 — Сонголтууд ба төлөөлөх утгууд

| # | Параметр | Сонголт (category) | Төлөөлөх утгууд |
|---|---|---|---|
| C1 | from | Илгээгч дансны төлөв | Хүчинтэй · Царцаагдсан · Байхгүй |
| C2 | to | Хүлээн авагч данс | Хүчинтэй (from-оос өөр) · Байхгүй · from-той ижил |
| C3 | amount | Дүнгийн тэмдэг | Эерэг · 0 · Сөрөг |
| C4 | amount | Дүн vs үлдэгдэл (хөрвүүлсний дараа) | Багтана · Үлдэгдэлтэй яг тэнцүү · Үлдэгдлээс хэтэрнэ |
| C5 | amount | Дүн vs өдрийн үлдсэн лимит (хөрвүүлсний дараа) | Багтана · Үлдсэн лимиттэй яг тэнцүү · Лимитээс хэтэрнэ |
| C6 | currency | Валют | Дансны валюттай ижил · Өөр (ханшаар хөрвүүлнэ) |
| C7 | *(далд орчин)* | Өнөөдөр лимитээс хэрэглэсэн хэмжээ | Огт хэрэглээгүй · Хэсэгчлэн хэрэглэсэн |

**Далд орчны сонголтууд:** C7 (өдрийн лимит өмнө нь хэр дүүрсэн бэ) болон from дансны үлдэгдэл нь хүсэлтийн биед байдаггүй ч үр дүнд нөлөөлдөг. C4/C5-ийн "яг тэнцүү", "хэтэрнэ" гэсэн утгууд нь ийм далд төлөвөөс шалтгаална.

### A2 — Хязгаарлалтууд

| Утга | Тэмдэглэгээ | Үндэслэл |
|---|---|---|
| C1 Царцаагдсан, C1 Байхгүй | **[ERROR]** | from буруу бол бусад сонголтоос үл хамааран алдаа буцна. Хослуулах нь өөр алдааг нууна (error masking). |
| C2 Байхгүй, C2 from-той ижил | **[ERROR]** | to буруу бол дүнгээс үл хамааран алдаа буцна. Нэг удаа шалгахад хангалттай. |
| C3 0, C3 Сөрөг | **[ERROR]** | ERROR_BAD_AMOUNT. Үлдэгдэл/лимитийн харьцуулалт утгагүй болно. |
| C4 Үлдэгдлээс хэтэрнэ | **[ERROR]** | ERROR_INSUFFICIENT |
| C5 Лимитээс хэтэрнэ | **[ERROR]** | ERROR_LIMIT |
| C1 Хүчинтэй | **[property FromOK]** | C2-C5 нь зөвхөн from зөв үед утгатай. |
| C3 Эерэг | **[property Pos]** | C4, C5 нь **[IF Pos]**: дүн эерэг үед л үлдэгдэл/лимиттэй харьцуулна. |
| C4 Яг тэнцүү, C5 Яг тэнцүү | **[SINGLE]** | Хязгаарын утга. Нэг удаа энгийн нөхцөлд шалгахад хангалттай, бусадтай хослуулах нэмэлт мэдээлэл өгөхгүй. |
| C5 Үлдсэн лимиттэй яг тэнцүү | **[IF Partial]** | Лимит хэсэгчлэн хэрэглэгдсэн үед "үлдсэн лимит" гэсэн хязгаар утга учиртай. |
| C6 Өөр | **[property Conv]** | Хөрвүүлэлттэй үед C4-ийн "зөвхөн хөрвүүлсний дараа хэтэрнэ" гэсэн сонирхолтой тохиолдол (S17) гарна. |

**Тоо (Лекц 6-ын find жишээний адил):**

- Бүрэн олонлог: C1×C2×C3×C4×C5×C6×C7 = 3 × 3 × 3 × 3 × 3 × 2 × 2 = **972**
- Хязгаарлалтын дараа:
  - [ERROR] утга бүр нэг удаа: Царцаагдсан, Байхгүй(from), Байхгүй(to), ижил, 0, сөрөг, хэтэрсэн үлдэгдэл, хэтэрсэн лимит = **8**
  - [SINGLE] утга бүр нэг удаа: үлдэгдэлтэй тэнцүү, үлдсэн лимиттэй тэнцүү = **2**
  - Үлдсэн хүчинтэй хослолууд: Хүчинтэй × Хүчинтэй × Эерэг × Багтана × Багтана × C6(2) × C7(2) = **4**
- **972 → 14** (8 + 2 + 4)
